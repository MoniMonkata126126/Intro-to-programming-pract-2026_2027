## Преговор

### Бройни системи

Бройна система е съвкупност от числа и правила за определяне на техните математически стойности. Например, ние използваме десетичната бройна система в ежедневието си.

Бройните системи имат:
- Основа - с колко на брой различни символи разполага тя (десетичната е с основа 10)
- Вид запис 
   - Позиционен - съвкупност от символи, залепени един до друг (143) 
   - Полиномиален - реална стойност (1 \* 10<sup>2</sup> + 4 \* 10<sup>1</sup> + 3 \* 10<sup>0</sup>)

#### Често срещани позиционни системи в програмирането:

Двоична (Binary) 
- Основа 2
- 0, 1

Шестнайсетична (Hexadecimal) 
- Основа 16 
- 0, 1, ..., 9, A, B, C, D, E, F

Осмична (Octal) 
- Основа 8 
- 0, 1, ..., 7 
- По-рядко срещана

#### Преминаване в друга бройна система

От десетична 
- Делим на основата, взимаме остатъка и го записваме 
- Продължаваме докато не стане 0 
- Записваме числото в обратен ред на взетите остатъци 
- 2254<sub>(10)</sub> -> ??<sub>(16)</sub> - 2254 / 16 = 140 ост. 14 - 140 / 16 = 8 ост. 12 - 8 / 16 = 0 ост. 8 
   - Получихме 8CE<sub>(16)</sub>

Към десетична 
- Пресмятаме стойността от полиномиалния запис на числото 
- 8CE<sub>(16)</sub> -> ??<sub>(10)</sub> 
   - 8\*16<sup>2</sup> + 12\*16<sup>1</sup> + 14\*16<sup>0</sup> = 8\*256 + 12\*16 + 14 = 2048 + 192 + 14 = 2254<sub>(10)</sub>

От двоична към шестнайсетична (осмична) 
- Делим числото на групи по 4 (3) бита отдясно наляво, като запълваме с нули отляво, ако не достигнат 
- Обръщаме всяка група в съответната шестнайсетична (осмична) цифра

От шестнайсетична (осмична) към двоична 
- Обръщаме всяка шестнайсетична (осмична) цифра в съответното ѝ двоично число

#### Събиране на двоични числа без знак

```
   ..
   0011 (3)
+
   0110 (6)
--------------
   1001 (9)
```

#### Умножение на двоични числа без знак

```
   0110 (6)
*
   0010 (2)
-------------
   0000
  0110
 0000
0000
-------------
0001100 (12)
```

#### Числа със знак

1's complement 
- Обръщаме всеки бит 
- -6<sub>(10)</sub> = 1001<sub>(2)</sub> (6<sub>(10)</sub> = 0110<sub>(2)</sub>) 
- Недостатъци 
   - Две нули - 0000 и 1111 
   - Събирането и умножението не работят по същия начин, като без знак

2's complement 
- Обръщаме всеки бит И добавяме единица 
- -6<sub>(10)</sub> = 1010<sub>(2)</sub> (6<sub>(10)</sub> = 0110<sub>(2)</sub> -> 0110<sub>(2)</sub> = 1001<sub>(2)</sub> -> 1001<sub>(2)</sub> + 1<sub>(2)</sub> = 1010<sub>(2)</sub>) 
- Вече операциите работят по същия начин:
```
    .
   0011 (3)
+
   1010 (-6)
--------------
   1101 (-3) (убедете се сами, че числото наистина е -3)
```
